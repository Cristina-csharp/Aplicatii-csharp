# DreptunghiApp

## Scop
Aplicație C# de consolă care calculează aria, perimetrul și diagonala unui dreptunghi.
Programul nu acceptă valori negative sau zero.

## Tehnologii
- C# / .NET
- Visual Studio
- Git și GitHub

## Rulare
1. Descarcă proiectul: `git clone https://github.com/NUME_UTILIZATOR/Aplicatii-CSharp.git`
2. Deschide folderul `DreptunghiApp` în Visual Studio.
3. Apasă Ctrl+F5.
4. Introdu lungimea și lățimea.

## Exemplu de execuție
    Lungime: 12
    Latime: 4
    Aria = 48
    Perimetrul = 32
    Diagonala = 12.65
